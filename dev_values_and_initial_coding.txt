# ── Story 4.10 — Static Terraform + Python validation ────────────────────────
# Run from infra/envs/dev/ — no AWS connection needed

# 1. Download providers locally (-backend=false skips S3 backend init)
terraform init -backend=false

# 2. Validate all .tf files for syntax and wiring errors
terraform validate

# 3. Enforce canonical Terraform formatting (rewrites files in place)
terraform fmt -recursive infra/

# 4. Scan Terraform for security misconfigurations
#    Install first (one-time): pipx install checkov
checkov -d infra/ --framework terraform

# 5. Static security analysis of Lambda Python source
#    Run from project root
#    -ll = MEDIUM+ severity, -ii = MEDIUM+ confidence
bandit -r src/lambda/ -ll -ii
